# Claude Code - Uebersicht

Bereich fuer die eigene Kompetenz im Umgang mit Claude Code. Enthaelt den Lernplan zum Skool-Kurs, Kurs-Notizen je Modul und ein Retro-Log ueber Aenderungen an Arbeitsregeln und Settings. Die Regeln selbst leben in `~/.claude/CLAUDE.md` und in den Claude-Settings — hier im Vault steht nur das Warum und die Wirkung dieser Aenderungen, nicht die Regeln selbst.

## Einstieg

- [[Lernplan]] - Modulplan zur Skaile Academy (Skool, Sebastian Kauffmann), ein Abend pro Woche
- [[Retro-Log]] - datierte Eintraege zu Aenderungen an Arbeitsregeln und Settings
- Ordner `Kurs-Notizen/` - eine Datei pro Kursmodul
- [[Vorlage Kursmodul]] - Vorlage fuer neue Kurs-Notizen

## Verwandt

- [[Skills-Uebersicht]]
- [[Planung-Uebersicht]]

## Lernziele

- **KI-Orchestrierung** - verstehen wann Sub-Agents, Effort-Stufen und Kontextgroesse den Unterschied machen, statt pauschal auf Maximaleinstellungen zu gehen.
- **Software-Handwerk** - Claude Code als Werkzeug fuer echte Code-Arbeit sauber einsetzen, inklusive Grenzen und Fehlerquellen kennen.
- **Arbeitsorganisation** - die eigene Nutzung so strukturieren, dass Wochenlimits und Kontingent nicht durch unbedachte Defaults verbrannt werden.
