# Lernplan Skool-Kurs Claude Code

## Kurs

- **Name:** Skaile Academy - Claude Code
- **Anbieter:** Sebastian Kauffmann
- **Plattform:** Skool, https://www.skool.com/skaile-academy
- **Inhalt laut oeffentlicher Seite:** Claude Code, MCPs, Skills und Automationen; Live Q&As, Module, Building Challenges. Zielgruppe Founder, Builder, Creator.
- **Preis:** 79 USD pro Monat (Stand 2026-09-24, oeffentliche Seite)
- **Modulliste:** steht nur im Classroom hinter dem Login, wird nachgetragen.

## Regeln fuer diesen Plan

- Ein Abend pro Woche ein Modul.
- Jede Etappe hat eine 20-Minuten-Minimalfassung: Modul ansehen, drei Stichpunkte notieren, hoechstens ein Regel-Kandidat festhalten.
- Regel-Kandidaten kommen erst nach Bestaetigung in die CLAUDE.md, nicht automatisch.
